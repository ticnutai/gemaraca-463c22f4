# סקירת מקורות — מאיפה עוד אפשר להביא פסקי דין ומראי מקומות

נבדק ב-22.9.2026 בחמישה מסלולי מחקר במקביל, וכל ממצא מרכזי אומת שוב ישירות.
המספרים כאן הם מדידות, לא הערכות — היכן שיש הערכה זה כתוב במפורש.

---

## שני הממצאים שמשנים את התמונה

### 1. `psakim.org` מפרסם מפתח מקורות מובנה — ואנחנו מנצלים ממנו שביעית

בסוף כל פסק יושב עץ HTML שבו **כל רמה היא צומת עם מזהה קבוע**:

```
מקורות → בבלי → גיטין → דף פח → עמוד ב
         ירושלמי → מגילה → פרק א → הלכה ט
         רמב"ם → הלכות תפילין → פרק א → הלכה ג
         שולחן ערוך → אבן העזר → סימן קכה → סעיף ד
```

המסכת, הדף והעמוד הם **ארבעה שדות נפרדים**, לא מחרוזת לפענוח. ההמרה היחידה
הנדרשת היא `פח` → 88, והיא דטרמיניסטית.

ויש **API הפוך**, לא מתועד, שאומת בפועל:

```
GET https://www.psakim.org/PsakimData/Tag?id=27793
→ תג "עמוד ב" (של גיטין דף פח), ושלושה פסקים שמצטטים אותו:
   fileID 13311 · «א (גיטין פח:)»            עוגן ogen4
   fileID 1910  · «גיטין פח ב»                עוגן ogen1
   fileID 379   · «קובעת הגמרא (גיטין פח:)»   עוגן ogen14
```

`fileID` הוא הפסק, `ogenID` הוא **עוגן למשפט המדויק בתוכו**. שורש העץ הוא תג
17204, ששמו `מפתח המקורות`.

**הפער אצלנו:**

| | |
| --- | --- |
| תגיות ב-`public/tag_psakim_map.json` | 3,533 |
| זוגות (דף, פסק) | **8,991** |
| פסקים שונים שהמפתח מצביע עליהם | 1,545 |
| מתוכם קיימים אצלנו | **61** |
| חסרים | **1,484** |
| הפניות מסוג `site-index` במסד | 1,315 |

הורדת 1,484 הפסקים החסרים תפתח **כ-8,000 מראי מקומות מתויגים ביד ברמת עמוד** —
בלי חילוץ ובלי AI.

**רישוי:** המקור היחיד בכל הסקירה עם תנאים מפורשים —
"השימוש בחומרים שבאתר פסקים מותר שלא למטרות מסחריות", עם חובת ייחוס
("נלקח מתוך אתר פסקים psakim.org"). `robots.txt` אינו אוסר דבר.

**מלכודת:** הדף מצהיר `charset=windows-1255` אבל מגיש UTF-8. לפענח כ-UTF-8.

### 2. שכבת "עין משפט" של ספריא — מיפוי דף→הלכה, נחלת הכלל

בקישורים של ספריא יש סוג נפרד, `type: "ein mishpat / ner mitsvah"`. זה **האפרט
המודפס הקלאסי**, לא זיהוי היוריסטי. אומת על כתובות ס"ג ע"ב:

```
Ketubot 63b:1 → Mishneh Torah, Marriage 21:10
Ketubot 63b:1 → Sefer Mitzvot Gadol, Negative Commandments 81
Ketubot 63b:1 → Tur, Even HaEzer 80
Ketubot 63b:1 → Shulchan Arukh, Even HaEzer 80:15
```

44 קישורי עין משפט בדף אחד, מתוך 239 קישורים בסך הכול (86 מפרשים, 51 הלכה,
23 שו"ת).

| | |
| --- | --- |
| היקף בכל הש"ס | **כ-131,800 קישורי עין משפט** (הוערך בשתי דרכים בלתי תלויות) |
| היעדים | שולחן ערוך, משנה תורה, טור, סמ"ג — **כולם נחלת הכלל בעברית** |
| צפיפות | 14–26 קישורים לעמוד |

כלומר: אפשר להציג בכל דף "אילו סימנים בשו"ע ואילו הלכות ברמב"ם נפסקו מכאן",
בלי AI, בלי חילוץ, ובלי מגבלת רישוי.

**שתי מלכודות שנמדדו:**
- להשתמש ב-`anchorRefExpanded` ולא ב-`anchorRef`: קישור שפרוש על טווח
  (`Berakhot 2a:5-2b:3`) מופיע פעם אחת, וכל העמודים שהוא מכסה רשומים רק במערך.
- ה-`category` בקישור הוא של **הקשר**, לא של הספר. ביאור הלכה וכסף משנה מגיעים
  תחת `Quoting Commentary` ולא `Halakhah`. סינון לפי `category == "Halakhah"`
  משמיט חלק גדול מספרות ההלכה.

**גישה:** `/api/links/<ref>?with_text=0` מקטין את התשובה פי 8.8. אין מגבלת קצב
מתועדת; נמדדו 25 בקשות במקביל (~17/שנייה) בלי שגיאה. בקשה לכל המסכת בבת אחת
נכשלת ב-504 — חייבים עמוד אחר עמוד. לחלופין: `dump.tar.gz` (2.56 ג"ב, נבנה
יומית) או קובצי ה-CSV (645 מ"ב, חודשי).

## ההנחה על "מראה מקומות בסוף הפסק"

נבדקה בפועל על 2,696 פסקי gov.il ועל 2,594 של דעת: **אפס** מהם מסתיימים ברשימת
מקורות. 21% מצטטים דף — אבל בתוך המשפט (`הגמ' במסכת בבא בתרא דף קלח עמוד ב`).

בית דין משפט צדק: הערות שוליים נקיות ומתוחמות, אבל **0 מתוך 28 פסקים מצטטים דף
בבלי בכלל** — הוא מצטט שולחן ערוך ואחרונים.

**המקור היחיד שבו אפשר לבנות אינדקס מהרשימה בלבד, בלי חילוץ ובלי AI, הוא
psakim.org.**

## תיקון לדבר שנאמר קודם

השדה `citations` בקאש של בית הדין דאמריקה **אינו** רשימת מקורות שהבית דין מפרסם.
הוא שדה שנוצר אצלנו: `download-bethdin-psakim.mjs` מריץ ביטוי רגולרי על הטקסט
המחולץ ושומר את התוצאה. 25 ההפניות שיובאו ממנו תקינות — כל אחת אומתה מול טווח
הדפים של המסכת — אבל הן תוצר חילוץ, לא תיוג רשמי.
